# 网站定位与使用说明

> 不对外展示，供建设与维护使用。

## 一句话定位

本站**只做流程教程**：不办业务、不发通知、不追时效。

- **不办业务**：这里没有在线表单、没有审批入口，只教「先做什么、再做什么、要交什么材料」，办手续仍要到学校系统或学院办公室。
- **不发通知**：不发布活动通知、临时通知、当年评选通知；这类信息以学校 / 学院官方渠道为准，本站只写「每年都差不多」的固定流程。
- **不追时效**：具体日期、名额、金额一律用 `【　】` 留出，不写死；当年通知由同学去官网核对。

## 八个专区怎么用

| 专区 | 管什么 | 什么时候来 |
|---|---|---|
| `02_新生专区` | 报到、迎新、党团转接、选课入门、导师双选 | 入学前后 |
| `03_在校学习专区` | 请假、选课、考试、学籍、毕业设计、学术资源、专利软著 | 整个在读阶段 |
| `04_奖助专区` | 奖学金、助学金与贷款、困难认定、三助一辅 | 每学年评选期 |
| `05_党团专区` | 党团组织关系、党员发展、班级与班委 | 转接、发展、换届时 |
| `06_生活与证件专区` | 宿舍、一卡通、网络、场地、心理医保、学生证与证明 | 日常 |
| `07_实习就业与毕业专区` | 实习、就业、升学、毕业、离校 | 出口阶段 |
| `08_文件专区` | 请假条、申请表、证明与协议模板下载 | 需要填表时 |
| `09_问题专区` | 系统问题、材料审核、流程卡点、找谁问 | 卡住时 |

`00_网站说明`（维护用）、`01_首页`（门户）、`10_关于与联系`（边界与联系）、`11_全局功能与维护`（技术能力）是支撑板块，不单独占一个专区。

## 内容口径（全站统一）

- **以现行为准**：所有流程按学院现行做法整理；线上网站若还留着未同步更新的旧说明，以本材料包为准。
- **党组织关系**：本院在党务系统选「**工学部党委**」。
- **校区称谓**：南海校区与佛山校区是同一校区，统一用「**佛山**」。
- **附件**：均为电子科学与工程学院（微电子学院）现行版本，集中在 `08_文件专区/附件/`。
- **联系方式**：各页「找谁问」只列具体经办部门；学院各办公室的姓名 / 电话 / 办公室统一在 `09_问题专区/04_找谁问与反馈.md`。
- **占位写法**：`【　】` 表示待填写，填完删掉括号；不明确的日期、名额、金额一律留空，不猜、不写死。

## 与线上网站的关系

目标站点 `https://qiqida.github.io/` 已有 freshman / leave / party / internship / graduation / other / download / faq 八个页面。本材料包按新板框重组后，各页面与专区的对应见根目录 `README.md` 的对照表；上线时以本材料包的板块命名为准。
