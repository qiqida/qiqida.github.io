# 搜索与索引

> 贯穿全站，不单独成页。对应 `01_首页/02_全局搜索入口.md` 的后台能力。

## 索引字段

每个流程页建立以下索引项：

| 字段 | 来源 |
|---|---|
| 专区名 / 页面标题 | 文件名与一级标题 |
| 适用对象 | 六段式第 1 段 |
| 关键步骤 | 「平台操作步骤」小标题与流程节点 |
| 常见卡点 | 六段式第 4 段、FAQ 问答标题 |
| 附件名 | 「相关文件内容」里的下载链接文字 |
| 经办部门 | 「找谁问」 |

## 搜索建议

- 支持同义词：请假 = 病假 / 事假 / 出省报备；退宿 = 校外住宿；学生证 = 研究生证；毕设 = 毕业设计 / 学位论文。
- 无结果时回退到 `01_首页/03_场景速查.md`。
- 搜索关键词预置表见 `01_首页/02_全局搜索入口.md`。
