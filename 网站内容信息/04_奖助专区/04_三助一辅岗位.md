# 三助一辅岗位

「三助一辅」指助研、助教、助管和辅导员助理岗位。岗位由学院按学期发布，申请和考核按当年通知执行。

## 助管怎么申请

想做助管的，填《助管报名登记表》交上去。表上要填：

- 培养层次、出生年月、政治面貌
- 主要学生工作经历、曾获奖励
- 自我评价及工作设想

```mermaid
    A[学院发布助管岗位] --> B[填写助管报名登记表]
    B --> C[提交申请]
    C --> D[学院考核录用]
```
