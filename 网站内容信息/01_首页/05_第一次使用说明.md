# 第一次使用说明：八个专区分别管什么

> 首页「第一次来？」入口。这条内容由原来的整站概览说明改写为常驻说明页，按新定位「不发通知」，不再作为通知发布。

工学部研究生事务服务中心把研究生常办的事按**八个专区**组织。先在下表找到你要办的事属于哪个专区，再进去按子栏目点开。

## 八个专区

| # | 专区 | 这里能找到什么 |
|---|---|---|
| 1 | **新生专区**（`02`） | 报到与迎新、新生党团转接、入学教育与体检、培养方案与选课、导师双选 |
| 2 | **在校学习专区**（`03`） | 请假与考勤、选课退课、考试与成绩、学籍异动、毕业设计、学术资源、专利与软著 |
| 3 | **奖助专区**（`04`） | 奖学金、助学金与助学贷款、家庭经济困难认定、三助一辅岗位 |
| 4 | **党团专区**（`05`） | 党组织关系转接、团组织关系与智慧团建、党员发展、班级与班委 |
| 5 | **生活与证件专区**（`06`） | 宿舍报修与退宿、一卡通补办、网络与账号、场地借用与活动申报、心理咨询与医保、学生证补办、在读与成绩证明 |
| 6 | **实习就业与毕业专区**（`07`） | 实习申请与外出报备、实习证明、就业推荐与三方协议、升学与出国交流、毕业资格审核、学位申请与论文送审、毕业材料与档案、离校手续 |
| 7 | **文件专区**（`08`） | 请假条与报备单、申请表与审批表、证明与协议模板、申请书与总结模板、附件与截图归档 |
| 8 | **问题专区**（`09`） | 系统操作问题、材料与审核问题、流程卡点、找谁问与反馈 |

另外三个支撑板块：`00_网站说明`（建设维护用，不展示）、`01_首页`（门户）、`10_关于与联系`（网站说明、咨询方式、办事地点）、`11_全局功能与维护`（搜索、移动端、版本备份，不单独成页）。

## 内容边界

本站**只教流程，不办事**：没有在线表单、不受理申请、不发布通知、不追当年时效。具体日期、名额、金额以学校 / 学院官方通知为准；本站把每年固定的步骤写清楚。

## 遇到问题去哪个专区

- 不知道该办什么 → `01_首页/03_场景速查.md`
- 卡在某一步、系统报错 → `09_问题专区/01_系统操作问题.md`、`03_流程卡点.md`
- 不知道找哪个部门 → `09_问题专区/04_找谁问与反馈.md`
- 需要下载表格 → `08_文件专区`

## 三条口径

- **以现行为准**：所有流程按学院现行做法整理；线上网站若还留着旧说明，以本站为准。
- **教学期间出省**：一律先做线上请假报备，见「在校学习专区 → 请假与考勤」。
- **联系方式**：辅导员、教务员、实验员等各办公室的姓名、电话、办公室，见「问题专区 → 找谁问与反馈」；不逐页重复。
