# 班级与班委

## 怎么报名

想进班委的，填《班委报名表》交给班级负责人。表上要填：

- 姓名、性别、民族、出生年月、籍贯、政治面貌
- 专业、报名职位
- 电话、邮箱
- 个人简介、实践经历、获奖经历

```mermaid
    A[想报名的同学] --> B[填写班委报名表]

    C --> D[班级选配 确定班委]
```
