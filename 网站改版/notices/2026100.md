# 这个网站怎么用：先搜关键词，再找对应专区

> 这一条置顶在最前面，第一次来先看这里。

## 三步找到你要办的事

### 第一步：搜关键词

顶部搜索框直接输入你正在办的事的俗称：

| 你会搜的词 | 直达 |
|---|---|
| 请假、病假、事假、出省报备 | 在校学习专区 → 请假与考勤 |
| 报到、迎新、迎新码 | 新生专区 → 报到与迎新 |
| 导师双选、选导 | 新生专区 → 导师双选 |
| 选课、退课、培养方案 | 在校学习专区 → 选课与退课 |
| 休学、复学、转专业 | 在校学习专区 → 学籍异动 |
| 奖学金、助学金、困难认定、三助 | 奖助专区 |
| 党组织关系、智慧团建、入党 | 党团专区 |
| 报修、退宿、一卡通、校园网 | 生活与证件专区 |
| 开证明、在读证明、成绩单 | 生活与证件专区 → 在读与成绩证明 |
| 实习、三方协议、出国境 | 实习就业与毕业专区 |
| 查重、送审、答辩、离校 | 实习就业与毕业专区 → 学位申请与论文送审 |
| 请假条、申请表、模板下载 | 文件专区 |
| 找谁问、办公室电话 | 问题专区 → 找谁问与反馈 |

### 第二步：找对应专区

首页第一屏是八个专区卡片。**鼠标悬停卡片就能先看到里面有哪些子板块**，不用点进去才知道。

首页下方还有一块**常用事务**，用你平时怎么说来找（"我要请假"、"我要开在读证明"），六条最高频的事，点一下直达。

| 专区 | 管什么 | 什么时候来 |
|---|---|---|
| 新生专区 | 报到、迎新、党团转接、入学教育、培养方案、导师双选 | 入学前后 |
| 在校学习专区 | 请假、选课考试、学籍异动、毕业设计、学术资源、专利软著 | 整个在读阶段 |
| 奖助专区 | 奖学金、助学金与贷款、困难认定、三助一辅 | 每学年评选期 |
| 党团专区 | 党组织关系、团组织关系、党员发展、班级与班委 | 转接、发展、换届时 |
| 生活与证件专区 | 宿舍、一卡通、网络、场地、心理医保、学生证与证明 | 日常 |
| 实习就业与毕业专区 | 实习、就业、升学、毕业、离校 | 出口阶段 |
| 文件专区 | 请假条、申请表、证明与协议模板下载 | 需要填表时 |
| 问题专区 | 系统问题、材料审核、流程卡点、找谁问 | 卡住时 |

### 第三步：照着步骤走

每个流程页都按同一套结构写：**适用对象 → 准备材料 → 平台操作步骤 → 常见卡点 → 找谁问 → 更新时间**。

带流程图的页面，把每一步先后顺序画出来了，照着走就行；带表格的页面列了哪些材料要提前备好；「找谁问」写的是这件事真正要打交道的具体部门。

## 手机上怎么看

- 卡片右上角有一个箭头，点一下展开子板块；点卡片其他地方直接进专区。
- 每个专区页顶部有本页目录，点一下跳到对应小节。
- 长表格可以左右滑动，流程图也能放大看。

## 卡住了怎么办

按情况去**问题专区**：

- 系统报错、登不进去 → 系统操作问题
- 材料被退回、不清楚要什么 → 材料与审核问题
- 卡在某一步不知道下一步 → 流程卡点
- 不知道该找谁 → 找谁问与反馈

## 一句话总结

本站**只教流程，不办事**。没有在线表单，不受理申请、不审批。当年的日期、名额、金额以学校与学院官方通知为准。
