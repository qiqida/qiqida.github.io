# 网站改版 · 预览版

这个文件夹是按新结构重做的整站，**目前只是预览，站点根目录（`index.html`、`pages/`、`data/`、`assets/`）一个字节都没动**。

## 怎么看预览

```bash
cd 网站改版/tools
python make.py
```

然后用浏览器打开 `网站改版/_preview/index.html`。

（本地起服务器看更准：`python -m http.server 8907`，然后访问
`http://localhost:8907/网站改版/_preview/index.html`）

## 这版改了什么

### 1. 八个专区重新命名

| 原结构 | 新结构 |
|---|---|
| 请假申请 | **在校学习专区**（含请假与考勤、选课与退课、考试与成绩、学籍异动、毕业设计、学术资源、专利软著） |
| 新生专区 | **新生专区**（保留，扩充为 5 个子板块） |
| 毕业专区 | 合并进 **实习就业与毕业专区** |
| 实习专区 | 合并进 **实习就业与毕业专区** |
| 党团事务专区 | **党团专区** |
| 文件专区 | **文件专区**（改为按五类模板索引） |
| 其他事务专区 | 拆分进 **生活与证件专区**（学生证、在读证明等） |
| 常见问题 | **问题专区** |

八个专区：**新生 / 在校学习 / 奖助 / 党团 / 生活与证件 / 实习就业与毕业 / 文件 / 问题**

### 2. 卡片取消简介

卡片只留图标、标题和子板块数量。简介文字放在专区页里的对应子板块上，不在首页重复。

卡片高度已统一（长标题截断为单行 + 省略号），8 张卡片完全等高。

### 3. 新增「重要通知」

- 首页在卡片区下方新增**重要通知**区块
- 置顶通知用大卡片突出显示（左侧蓝色竖条 + 「重要通知」徽标）
- 普通通知用紧凑行显示
- 「这个网站怎么用」已改成**置顶通知**，是全站第一条
- 原来的通知内容已清空，重新写了 3 条：
  - `2026100` 这个网站怎么用（置顶）
  - `2026101` 本站只教流程，不受理申请
  - `2026102` 八个专区分别管什么

### 4. 保留原有区块

以下区块都按原样保留：

- **热门问题**（读 `data/faq.json`）
- **热门搜索关键词**（读 `data/search-stats.json`，18 个词）
- **数据统计**（本周访问 / 资料数量 / 常见问题 / 重要通知）

### 5. 新增两个区块

- **我要办点事**：10 条场景速查，用学生平时怎么说来找（"我要请假" "校园卡丢了"），不用记部门名称
- **热门流程**：Top6 常用流程直接跳

### 6. 品牌区

按要求**完全没动**。

## 关于工具脚本

`tools/` 里的脚本只读写 `网站改版/` 目录，不会碰站点根目录。
`make.py` 的执行顺序是固定的：**build → assets → home → preview**，顺序不能乱
（`build.py` 会清空 `pages/`，`assets.py` 生成 `data/`，两者有先后依赖）。
