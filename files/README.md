# 下载文件目录

本目录存放可供学生下载的表格与材料。

## 当前状态

目前为**占位文本文件**，便于网站下载功能正常运行。请辅导员将正式 `.docx` / `.pdf` 模板上传至此目录，并同步修改 `data/downloads.json` 中的 `file` 字段。
